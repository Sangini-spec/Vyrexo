## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or [Bun Runtime](https://bun.sh)
- Git

### Installation
```bash
# Clone the repository
git clone <your-repo-url>
cd <repo-name>

# Install dependencies
npm install
# or with Bun:
bun install
```

### Running Locally
```bash
npm run dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### Running Automated Tests
```bash
bun test
# or
npm test
```
