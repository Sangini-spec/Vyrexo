# AuraBeauty — Cosmetics & Skincare E-Commerce Platform

A clinical, botanical skincare e-commerce platform with specialized routine recommendations, dermatological ingredients breakdown, responsive cart drawer, and checkout workflow.

## Key Features
- **Skin-Type Routine Filter**: Immediate personalization for Sensitive / Barrier Repair, Dry & Dehydrated, Oily / Blemish-Prone, and Mature skin.
- **5-Step Facial Kits & Targeted Actives**: Complete bundles and single-origin treatments.
- **Quick-View Ingredients Modal**: Full dermatological profile, active concentrations, and clinical trial results.
- **Dynamic Cart Drawer**: Live subtotal, free delivery progress meter, and coupon engine (`GLOW20` for 20% discount).
- **Checkout & Order Tracker**: End-to-end simulated ordering with real-time laboratory preparation steps.
